vw_cliente_card

Cartão do cliente (view)

view 541 linhas em 2026-11-12

Resumo simples

É a lista de clientes que a tela de Clientes mostra: cada cliente com a contagem dos geradores dele e um "estado" que diz o que falta fazer (sem iClass, sem gerador, sem ficha, completo, validado).

Detalhes técnicos: restrições, índices e SQL da view

Definição da view (SQL)

 WITH ger AS (
         SELECT g.omie_cliente_id,
            count(*) AS n_geradores,
            count(g.ativo_id) AS n_com_ativo,
            count(g.ficha_levantamento) AS n_com_ficha,
            count(*) FILTER (WHERE g.validado) AS n_validados,
            (array_agg(g.nome_fantasia ORDER BY g.id))[1] AS primeiro_gerador
           FROM geradores_atg g
          WHERE g.arquivado = false
          GROUP BY g.omie_cliente_id
        )
 SELECT o.id,
    o.razao_social,
    o.nome_fantasia,
    o.cnpj_raw,
    o.cnpj_limpo,
    o.codigo_omie,
    o.iclass_id_encontrado,
    o.iclass_codigo_encontrado,
    o.status_conferencia,
    o.validado AS cliente_validado,
    o.validado_por AS cliente_validado_por,
    COALESCE(gr.n_geradores, 0::bigint) AS n_geradores,
    COALESCE(gr.n_com_ativo, 0::bigint) AS n_com_ativo,
    COALESCE(gr.n_com_ficha, 0::bigint) AS n_com_ficha,
    COALESCE(gr.n_validados, 0::bigint) AS n_validados,
    gr.primeiro_gerador,
        CASE
            WHEN o.iclass_id_encontrado IS NULL THEN 'SEM_ICLASS'::text
            WHEN COALESCE(gr.n_geradores, 0::bigint) = 0 THEN 'SEM_GERADOR'::text
            WHEN gr.n_com_ficha < gr.n_geradores THEN 'SEM_FICHA'::text
            WHEN o.validado AND gr.n_validados = gr.n_geradores THEN 'VALIDADO'::text
            ELSE 'COMPLETO'::text
        END AS estado
   FROM omie_clientes o
     LEFT JOIN ger gr ON gr.omie_cliente_id = o.id;
