Início / 4. Banco de dados

omie_clientes

Clientes (cadastro vindo do Omie, ligado ao iClass)

tabela 541 linhas em 2026-11-12

Resumo simples

É a lista de clientes da ATG. Cada linha é um cliente, com o código dele no Omie, o código dele no iClass e o resultado da conferência entre os dois. É a tabela principal: geradores, vendedor e histórico se ligam a ela.

Um cliente entra aqui de dois jeitos: pelo botão de novo cliente da plataforma (fluxo criar-cliente (cadastro no Omie e no iClass)) ou pela carga inicial da base existente. Não confirmado A carga inicial não está no repositório; deduzida pelo fato de existirem 541 clientes e campos de conferência que o código nunca grava.

Ligações que o banco não impõe

  • iclass_id_encontrado e codigo_omie apontam para sistemas externos (iClass e Omie); o banco não valida essa ligação.
  • A regra "vendedor só vê os próprios clientes" é aplicada só na tela (filtro no src/pages/Clientes.tsx); o banco não a impõe.

Regras que o banco impõe

  • RLS (acesso por linha): desligado.
  • Privilégios de tabela: papel anon = todos; papel authenticated = todos (fonte: consulta Q12).
  • Ao apagar um cliente, todos os geradores dele são apagados junto (chave estrangeira com exclusão em cascata em geradores_atg). As preditivas e o oxicatalisador desses geradores perdem a ligação, mas as linhas continuam (ver tabelas de cada um).
  • Ao apagar um vendedor, o cliente continua e o campo vendedor_id fica vazio.
  • Usada por criar_gerador validar_cadastro vw_cliente_card vw_conferencia_iclass dentro do banco.
