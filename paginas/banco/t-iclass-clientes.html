Início / 4. Banco de dados

iclass_clientes

Cópia de clientes do iClass

tabela 1.223 linhas em 2026-11-12

Resumo simples

Uma lista de clientes do iClass (1.223 linhas) com identificador, código, nome, CNPJ, e-mail e telefone. A única coisa do banco que a lê é a view vw_conferencia_iclass.

Não confirmado Quem carrega esta tabela e para que ela é consultada não estão no repositório. Pelo nome da view que a lê, serve para a conferência entre o cadastro e o iClass (vw_conferencia_iclass). Nenhum arquivo de src/ nem fluxo do n8n a acessa.

Relacionamentos

Não há chave estrangeira declarada no banco para este objeto.

Ligações que o banco não impõe

  • iclass_id corresponde a omie_clientes.iclass_id_encontrado (ligação usada pela view de conferência), sem chave estrangeira.

Regras que o banco impõe

  • RLS (acesso por linha): desligado.
  • Privilégios de tabela: papel anon = todos; papel authenticated = todos (fonte: consulta Q12).
  • RLS desligado e privilégios totais para anon e authenticated (A-003): uma cópia de dados pessoais de clientes sem restrição por linha.
  • Usada por vw_conferencia_iclass dentro do banco.

Quem lê e quem grava

No código da plataforma (src/)

Nenhum arquivo do src/ acessa este objeto diretamente.
